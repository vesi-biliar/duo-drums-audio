# Duo Drums · prueba de audio remoto

Ocho WAV PCM 16 bits, uno por pista del kit Soul cálido. Sirven para probar descarga e importación directa de WAV desde GitHub sin decodificar FLAC en Android. Este repositorio no reemplaza el catálogo de 80 opciones ni sus cinco capas de intensidad. Cada archivo fue verificado contra el hash Git de su fuente y recortado hasta 0,5 ms antes del ataque. `manifest.json` conserva origen, licencia y SHA-256 del WAV.

Créditos: AVL Drumkits de Glen MacArthur (CC BY-SA 3.0, con excepción para música); Virtuosity Drums de sfzinstruments (CC0). Ver `AVL-License.pdf`, `Virtuosity-CC0.txt` y las URLs de origen del manifiesto. Los WAV derivados de AVL mantienen CC BY-SA 3.0.
